Before you upload — this decides the result

  • Light the inside of the mouth. This matters more than everything else combined. If the mouth interior is in shadow, the result gets a dark gap between the lips and no setting fixes it.
    Measured: a well-lit clip came out almost clean; a clip with the mouth in shadow was rejected on sight. Same model, same settings.
  • Face the camera. Turning away, or a hand across the face, breaks the alignment for those frames.
  • Fill the frame with the head and shoulders. A distant face has less real detail to work from.
  • Give it clean audio. The voice is cloned from this clip, so background noise and music get cloned too. A separate clean sample is better.
  • A few seconds is enough. The clip is looped to cover your script — it does not need to be as long as the script.
