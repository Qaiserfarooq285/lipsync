# Presenter Consent Record

This file is a hard gate. `core/consent.py` parses it, and the pipeline refuses to run
against any asset outside `assets/samples/` until the status line below reads
`STATUS: GRANTED` and every required field is filled in.

Until then the system builds and self-tests on synthetic placeholders only.

---

## How to grant consent

1. Obtain **written** permission from the presenter covering: cloning their voice,
   synthesising their likeness/lip movement, and the intended distribution of the
   resulting videos (including commercial use, if applicable).
2. Store the signed document somewhere durable and reference it below. Do **not** commit
   the signed document to this repo.
3. Fill in every `<...>` field.
4. Change the status line at the top of this file to exactly:

   ```
   **STATUS: GRANTED**
   ```

5. Re-run the pipeline. `python -m core.consent --check` will confirm the gate is open.

Revoking consent means setting the status back to `NOT GRANTED`. Do that first, then
delete the derived media.
